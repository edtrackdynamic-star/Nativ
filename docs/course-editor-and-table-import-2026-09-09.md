# שיפור עריכת קורסים והדבקת טבלה — 2026-09-09

- שדות קיבולת ומספר דירוגים נשמרים כטיוטת קלט במהלך ההקלדה, ומומרים למספרים רק לפני שמירה ותצוגה מקדימה. שדה ריק אינו מוחלף באפס; השמירה בודקת מספרים שלמים וסדר קיבולות.
- בחירת המורים נעשית בחיפוש לפי חלקי שם עם בחירה מרובה והסרה. משתמשים רק ברשימת המורים הפעילים שהשרת מחזיר לארגון.
- הדבקת TSV מאקסל/Sheets: כותרת אופציונלית, התאמת עמודות, תמיכה בתאים מצוטטים ורב-שורתיים, תצוגה מקדימה והתאמת מורים מדויקת. התאמות חסרות או עמומות מחייבות אישור ידני. טקסט וקישורים נבדקים לפני הוספה; אין יצירת משתמשים או הרצת תוכן תאים.
- ההוספה יוצרת מקבצים חדשים ואינה דורסת מקבצים קיימים. לאחר ההוספה בוחרים כיתות ודירוגים בעריכה הרגילה ושומרים במפורש. מגבלות: 200 שורות להדבקה, 20 מקבצים בתהליך, 40 קורסים במקבץ. עמודת קיבולת שלא מופתה מקבלת 0/18/22; תא ריק בעמודה ממופה דורש תיקון.
- בדיקות: pnpm check עבר (73 בדיקות, lint, טיפוסי לקוח ושרת ובנייה); בדיקת התקנה מקומית עברה. בדפדפן Chrome עם API מדומה נבדקו מחיקת קיבולת ודירוג, חסימת שמירת קיבולת ריקה, חיפוש ובחירת מורה, חסימת יבוא עם מורה לא מזוהה, פתרון ידני והוספה, וללא גלישה אופקית ברוחבים 320/390/1280. הבדיקה אינה התחברות חיה או שמירת נתונים אמיתיים.
- היקף הפריסה: Hosting של נתיב בלבד. אין שינוי ב-Functions, Rules או בנתונים חיים.

## תיקון: הדבקה בתוך המקבץ
- בוטלה יצירת מקבצים ביבוא: לכל מקבץ אזור הדבקה משלו; כיתות, דירוגים וקורסים קיימים נשמרים. אין צורך בעמודת מקבץ.
- נוספה תמיכה בטבלאות Markdown עם מפרידי | והסרת שורת יישור. שורה ראשונה נחשבת נתונים כברירת מחדל; כותרות הן בחירה מפורשת. מוצגות שש שורות לדוגמה לפני התאמת עמודות.
- הדבקה, פענוח ותצוגה מקדימה אינם מוסיפים קורסים. רק לחיצה על הוספה למקבץ מוסיפה לטיוטה; שמירה נשארת פעולה נפרדת. אין יבוא של דוגמת המשתמש לנתונים חיים.
- נבדקות כפילויות מול קורסים קיימים ומגבלת 40 קורסים כולל הקיימים.
- 75 בדיקות עברו, כולל כל שש שורות הדוגמה ויעל–תאטרון בשורה הראשונה. בדיקת Chrome מקומית עם callback מדומה אימתה שאין שינוי לפני לחיצה, הוספת שש רשומות לאחר לחיצה, ופריסה ברוחבים 320/390/1280. אין בדיקה על נתוני בית הספר.
