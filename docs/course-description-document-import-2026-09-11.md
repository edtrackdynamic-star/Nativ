# ייבוא תיאורי קורסים ממסמך

## מטרת המהלך

רכז שיבוץ יכול לצרף למחזור מסמך תכנים קיים, לזהות ממנו שמות קורסים, מורים ותיאורים, ולבחור אילו תיאורים להחיל על טיוטת הקטלוג. התהליך מסייע בהזנה ואינו מחליף את הבדיקה והעריכה של הרכז.

## זרימת העבודה

1. הרכז מגדיר מסמך מקור יחיד למחזור: קישור ל-Google Docs או קובץ Word מסוג `.docx` בגודל של עד 4MB. קישור וקובץ אינם יכולים להיות מוגדרים יחד.
2. רק לאחר לחיצה על "זיהוי תיאורי קורסים" תוכן המסמך נשלח ל-Gemini.
3. Gemini מחזיר הצעות הכוללות שם קורס, שם מורה, תיאור והתאמה אפשרית לקורס קיים.
4. הרכז בודק את ההתאמות, משנה יעד ותיאור לפי הצורך ומאשר במפורש החלפה של תיאור קיים.
5. לחיצה על "החלת התיאורים שסומנו" מעדכנת את טיוטת הקטלוג בלבד. שמירת המחזור נשארת פעולה נפרדת של הרכז.

קובץ Word נשמר ב-Cloud Storage בנתיב ייעודי לארגון ולמחזור, ונפתח דרך Callable שבודק הרשאה לכל קריאה. מסמך Google נשאר במסמך המקורי, והקישור אליו הוא גם הקישור המוצג במערכת. הטקסט שנשלח לזיהוי מוגבל ל-120,000 תווים. מסמך Google פרטי צריך להיות משותף לקריאה עם חשבון השירות `369491378125-compute@developer.gserviceaccount.com`; כדי שמורים ותלמידים יוכלו לפתוח את הקישור, יש לשתף אותו איתם גם ב-Google Drive.

## הרשאות וחשיפה לתלמיד

- פעולת החילוץ זמינה רק לבעל הרשאת `nativ.assignment.manage` ונרשמת בצד השרת באמצעות המפתח הסודי הקיים של Gemini.
- המסמך מטופל כמקור בלתי מהימן; הוראות שמופיעות בתוכו אינן מבוצעות.
- המסמך מוצג לתלמיד רק אם הרכז הפעיל את האפשרות המתאימה. כשהאפשרות כבויה, השרת מסיר את הקישור ואת נתיב קובץ Word מתשובת הרשת לתלמיד.
- מנחה המשויך לקורס במחזור יכול לפתוח את המסמך הכללי. מנהל שיבוץ יכול לפתוח אותו גם לפני שמירת הטופס. תלמיד יכול להוריד קובץ Word רק אחרי פתיחת המחזור ורק כאשר הצגת המסמך הופעלה.
- כללי ה-Storage של EdTrack אינם מעניקים גישה ישירה לנתיב המסמכים של נתיב; קריאת Word מתבצעת בצד השרת תחת הרשאות ארגוניות. אין לשנות את כללי Storage של EdTrack לצורך המסלול הזה.
- התלמיד רואה רק את התוכן שנשמר בקטלוג. לאחר פרסום שיבוץ הוא יכול לפתוח את תיאור הקורס שאליו שובץ ולראות את שמות המורים.

## פריסה ואימות

השינוי דורש את פונקציות `uploadCycleDocument`, `downloadCycleDocument`, `extractCourseDescriptions`, `saveCycleCatalog`, `getChoiceContext`, `getInstructorWorkspace` ואת Hosting של נתיב. אין שינוי ב-Rules או בנתונים חיים. מסמך Google ממשיך לדרוש Google Drive API פעיל בפרויקט הענן.

האימות כולל בדיקות יחידה לחוזה הפלט של Gemini ולתצורת הטופס, בדיקות מערכת להרשאת החילוץ ולסינון קישור מוסתר, בדיקת בנייה ובדיקת ממשק שבה אין החלה אוטומטית ותיאור קיים מוגן מהחלפה לא מכוונת.
