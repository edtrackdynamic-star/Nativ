# נתיב — בחירה ושיבוץ קורסים

מאגר הקוד הנקי של אפליקציית נתיב. המאגר אינו כולל גיליונות, שמות תלמידים או
תוצרים מהמערכת ההיסטורית שבתיקייה שמעליו.

## מצב נוכחי

- מעטפת React ו-TypeScript בעברית וב-RTL.
- מודל ראשוני לתפקידים ויכולות.
- מודל תחום למחזור בחירה, מקבצים, קורסים, הגשות ואילוצים קשיחים.
- מעברי מצב מבוקרים עם בקרת גרסה ואירוע ביקורת.
- אימות דירוג מלא, נימוק אופציונלי, קיבולות ומדיניות חזרה על קורס.
- חוזים ומימושים מדומים לספריית EdTrack ולהערכת AI.
- Firebase Functions בדור שני עם Node.js 22.
- הגדרות אמולטורים וכללי Firestore חסומים כברירת מחדל.
- אין חיבור לנתוני אמת, לפרויקט Firebase או ל-Gemini.
- מסך המוכנות מציג מחזור אנונימי מקומי עם שני מקבצים ושישה קורסי הדגמה.

## עבודה מקומית

```powershell
pnpm install
pnpm dev
pnpm check
pnpm functions:build
```

הפעלת האמולטורים תתאפשר לאחר התקנת Firebase CLI והשלמת קובץ פרויקט מקומי.
אין להעתיק את `.firebaserc.example` לפרויקט אמיתי לפני אישור סביבת הפיתוח.

## גבולות אבטחה

- הרשאות מקצועיות נבדקות לפי capabilities ולא לפי שם תפקיד בלבד.
- מנהל גישה אינו מקבל אוטומטית גישה לנתוני שיבוץ.
- קלט AI אינו אמור לכלול שם, דוא"ל, כיתה או מזהה תלמיד.
- פלט AI לא ישמש שיבוץ לפני אישור מפורש של רכז.
- סודות נשמרים בצד השרת בלבד ואינם חלק מהמאגר.
