# נתיב — בחירה ושיבוץ קורסים

מאגר הקוד הנקי של אפליקציית נתיב. המאגר אינו כולל גיליונות, שמות תלמידים או
תוצרים מהמערכת ההיסטורית שבתיקייה שמעליו.

## מצב נוכחי — ליבת ענן פרוסה

- מעטפת React ו-TypeScript בעברית וב-RTL.
- מודל ראשוני לתפקידים ויכולות.
- מודל תחום למחזור בחירה, מקבצים, קורסים, הגשות ואילוצים קשיחים.
- מעברי מצב מבוקרים עם בקרת גרסה ואירוע ביקורת.
- שכבת יישום לעבודה טרנזקציונית, הרשאות לפי capability ומפתחות idempotency.
- מאגר מקומי בזיכרון לבדיקות יחידה ומתאם Firestore מלא לזרימות השרת.
- מתאם Firestore שרתי לאותו חוזה, מאומת מול Emulator וללא חיבור ענן.
- אימות דירוג מלא, נימוק אופציונלי, קיבולות ומדיניות חזרה על קורס.
- חוזים ומימושים מדומים לספריית EdTrack ולהערכת AI.
- Firebase Functions בדור שני עם Node.js 22.
- הגדרות אמולטורים וכללי Firestore חסומים כברירת מחדל.
- אתר הייצור זמין ב־`https://edtrack-nativ.web.app` ומחובר ל־Firebase Auth המשותף של EdTrack.
- מסד `nativ`, כללי האבטחה ו־Functions codebase בשם `nativ` פרוסים ב־`edtrack-development`.
- חברות, ארגון ומנוי נקראים בצד השרת ממסד הליבה של EdTrack; תפקידי נתיב נשמרים במסד המוצר.
- נפרס מנגנון דיוור SMTP לפי המתווה שאושר ב־3 בספטמבר 2026, עם תור טרנזקציוני ובדיקת נמענים. טרם בוצעה בדיקת מסירה לתיבה אמיתית.
- חיבור Gemini אמיתי עדיין לא הושלם; הערכת ההדגמה שבקוד אינה מיועדת להחלטות על תלמידים אמיתיים.
- כניסה מקומית לחמישה בעלי תפקיד: מנהל גישה, רכז, תלמיד, צוות ערעורים ומזכירות.
- טופס בחירה עם דירוג ללא כפילויות, נימוק אופציונלי, שמירה אוטומטית וגרסאות.
- אצוות AI אנונימית מקומית חד-פעמית, סינון דוא״ל וטלפון, פלט גולמי ועותק מאושר הניתן לעריכה.
- מנוע שיבוץ דטרמיניסטי התואם לעקרונות המנוע ההיסטורי: מגישים תחילה, דירוג, AI מאושר כשובר שוויון, יעד/מקסימום, חזרה ואילוצים.
- אישור גרסת שיבוץ ופרסומה הן פעולות נפרדות; הפרסום יוצר רשומות הודעה באפליקציה ובדוא״ל.
- ערעור כולל דירוג ונימוק במקבץ, טופס מקורי בלחיצה, ניתוח השפעה, החלטה ללא שינוי מיידי וביצוע מפורש לאחר בדיקה חוזרת.
- ביצוע שינוי יוצר תיעוד גרסאות, דיווח באפליקציה ואירוע דיוור למזכירות ולתלמיד. הודעות הדגמה ישנות אינן נשלחות בדיעבד.
- מנהל גישה יכול לאייש כמה משתמשים לכל תפקיד, אך אינו רואה מידע מקצועי ללא תפקיד נוסף.

## עבודה מקומית

```powershell
pnpm install
pnpm dev
pnpm check
pnpm functions:build
pnpm test:emulator
pnpm test:system
pnpm emulators
```

לאחר `pnpm emulators` הממשק זמין ב־`http://127.0.0.1:5000` וממשק האמולטורים ב־`http://127.0.0.1:4000`.

בדיקות Firestore משתמשות תמיד בפרויקט המדומה `demo-nativ-local`. אין להעתיק
את `.firebaserc.example` לפרויקט אמיתי לפני אישור סביבת הפיתוח.

## גבולות אבטחה

- הרשאות מקצועיות נבדקות לפי capabilities ולא לפי שם תפקיד בלבד.
- מנהל גישה אינו מקבל אוטומטית גישה לנתוני שיבוץ.
- קלט AI אינו אמור לכלול שם, דוא"ל, כיתה או מזהה תלמיד.
- פלט AI לא ישמש שיבוץ לפני אישור מפורש של רכז.
- סודות נשמרים בצד השרת בלבד ואינם חלק מהמאגר.

## גבול הגרסה הפרוסה

ליבת הענן, אתר הייצור, Auth, הפרדת הנתונים ובדיקות החברות והמנוי מחוברים. נדרשים
עוד מפתח Gemini ייעודי, בדיקת מסירת מייל אמיתית, הפעלת App Check לאחר רישום
האתר, והקמת מחזור וקורסים אמיתיים לפני פתיחה למשתמשים.

פירוט הזרימות, הבדיקות והפערים לפני סביבת ענן נמצא ב־`docs/local-mvp-handoff.md`.

מתווה הדיוור המאושר והוראות טיפול במסירה: `docs/mail-delivery-2026-09-03.md`.
